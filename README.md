Food Order Management System

**Overview**
The Food Order Management System is a web-based application developed using ASP.NET Web Forms and Oracle Database. It is designed to streamline internal food ordering by replacing manual processes with a centralized and efficient digital solution.

**Features**
-Role-based Authentication – Secure login for employees and administrators
-Employee Dashboard – Place and track food orders
-Admin Dashboard – Monitor and manage all orders
-Food Item Management – Add, update, and remove menu items
-Centralized Order Records – Maintain consistent and reliable data
-Session Management – Ensures secure and controlled access

**System Architecture**
The application follows a three-tier architecture:
-Presentation Layer – ASP.NET Web Forms for user interface
-Business Logic Layer – C# for application logic and processing
-Data Layer – Oracle Database for data storage and management

**Technologies Used**
-ASP.NET Web Forms
-C#
-Oracle Database
-HTML, CSS
-Visual Studio
-Git & GitHub
